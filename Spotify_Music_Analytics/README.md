
# 🎵 Spotify Music Analytics Dashboard

An interactive **Spotify Music Analytics Dashboard** built using **Microsoft Excel** to analyze music streaming data, artist performance, genres, song popularity, and streaming trends.

## 📊 Project Overview

This project transforms Spotify music data into an easy-to-understand visual dashboard.

The dashboard uses charts and data analysis techniques to identify patterns in music streaming and explore the performance of different artists, songs, and genres.

## 🔗 Project File

📊 **[Open / Download Spotify Dashboard](./spotify.xlsx)**

## ✨ Dashboard Features

### 🎤 Top Streamed Artists
Analyzes and compares artists based on their total number of streams.

### 🎧 Genre Distribution
Shows the distribution of different music genres in the dataset.

### 📈 Streams & Popularity
Compares song streaming numbers with their popularity scores.

### ⭐ Song Popularity
Provides a visual comparison of popularity scores across different songs.

### 🎵 Genre-wise Streams
Analyzes the total number of streams across different music genres.

### 📅 Release Year Analysis
Explores streaming patterns based on the release year of songs.

## 🔍 Key Insights

The dashboard helps answer questions such as:

- Which artists have the highest number of streams?
- Which music genres are most represented?
- Which songs have higher popularity scores?
- How are streams distributed across different genres?
- Is there a relationship between song popularity and streams?
- How does streaming performance vary across release years?
